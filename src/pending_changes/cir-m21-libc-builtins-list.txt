List of the C library functions that are builtins, for the CIR back end

A new generated header, builtin_libc.h, lists the C library functions (libc
and libm) for which a call of __builtin_X can be translated to a call of X.
It is generated by dev_tools/builtins/generate-libc-builtins.py from the
same builtins_*.txt files as builtin_defs.h: X is listed if every scrape
file (GCC or Clang, any version) that lists both __builtin_X and X gives them
the same signature, except for compiler intrinsics, type-generic
classification functions, decimal and complex functions and a few other names
that the script documents.  Only the CIR
back end includes the header; builtin_defs.h, builtin_kinds.h and the
generator of the builtin tables are not changed, so the other configurations
behave as before.
